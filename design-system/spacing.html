Spacing & layout

No fixed 8-pt grid — space is fluid. Rhythm scales with the viewport via clamp().

The clamp rhythm

Spacing is expressed as clamp(min, viewport-unit, max) so it tightens on small screens and opens up on large ones. The recurring bands (resize this window to watch them move):

BandToken patternUsed for
Hairline1pxRules, pill borders

Elementclamp(16px, 2.5vh, 32px)Between related blocks
Groupclamp(40px, 6vh, 64px)Between groups / nav ↔ content

Content widths

--max-product · 1100px — the product column
--max-cta · 900px — the closing CTA
--max-copy · 38ch — measure for a paragraph of body copy. Lines never run longer than this so prose stays readable.

Corner radii

When in doubt, prefer a clamp() over a fixed pixel gap. The whole layout is meant to breathe between a phone and a wide desktop without breakpoints fighting it.
